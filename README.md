# Varaždin Edukativni MMO

## Opis projekta

Varaždin Edukativni MMO je edukativna multiplayer igra razvijena u Roblox Studio okruženju.

Cilj projekta je omogućiti igračima istraživanje povijesnih lokacija grada Varaždina kroz interaktivni multiplayer svijet, NPC interakcije, edukativne misije i kvizove.

Projekt kombinira elemente edukacije, istraživanja i multiplayer gameplaya kako bi igrači kroz zabavan način učili o povijesti, kulturi i znamenitostima Varaždina.

Projekt se razvija kao timski studentski projekt koristeći GitHub za organizaciju razvoja, dokumentacije i upravljanja zadacima.

---

# Glavne funkcionalnosti

- otvoreni multiplayer svijet
- istraživanje stvarnih lokacija Varaždina
- NPC vodiči i dijalozi
- edukativni kvizovi i misije
- sustav napretka igrača
- AI generirani 3D modeli lokacija
- interaktivne POI (Point of Interest) točke
- sustav nagrada i bedževa

---

# Gameplay

Igrači istražuju virtualnu rekonstrukciju Varaždina i kroz interakciju s NPC likovima, objektima i lokacijama dobivaju edukativni sadržaj.

Gameplay uključuje:
- istraživanje lokacija
- razgovor s NPC likovima
- rješavanje edukativnih kvizova
- izvršavanje misija
- skupljanje nagrada i napretka
